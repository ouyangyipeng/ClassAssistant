# 课狐 ClassFox 2.0

课狐用于课堂转录、关键词提醒、即时问答和课后笔记。桌面保留完整工作区和紧凑悬浮窗，微信小程序正式交付移至 v2.5，开发预览包含手机独立 BYOK 及连接电脑两条路径。

v2.0 的正式功能范围为桌面端。安装包、真实在线账户、微信真机和正式上架分别记录，见 [验证范围](project/validation.md)。

## 从这里开始

- 已安装桌面版：[首次使用](user-guide/quickstart.md) → [课堂工作流](user-guide/features.md)。
- 从 1.x 升级：[备份与导入](user-guide/migration.md)。
- 需要微信版：[v2.5 微信开发预览](user-guide/wechat.md)。
- 参与开发：[环境准备](getting-started/environment.md) → [开发与测试](getting-started/development.md)。
- 准备发布：[打包与发布](getting-started/packaging.md)。

每堂课的原文单独保存，总结不会替换原文。本地模式在电脑上处理内容；BYOK 会把相应音频或文字发送到选择的服务商。开始录音前取得参与者的知情同意，使用回答前核对事实。
