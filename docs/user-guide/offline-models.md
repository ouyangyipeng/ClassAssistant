# 国内下载与离线模型

ClassFox 2.1 的问答模型优先使用 ModelScope 固定版本下载，并保持与原始源一致的文件校验。网络中断会自动重试，已下载部分会保留。语音模型尚使用原始下载源，网络不通时可使用离线包。

## 使用百度网盘离线包

1. 从[官网下载区](https://class.nexa-lang.com/#download)打开百度网盘，下载自己电脑对应的 2.1 安装包。
2. 下载 `ClassFox-sensevoice-small-offline.zip` 和 `ClassFox-qwen35-4b-offline.zip`。只需要语音或问答时，可以只下载对应包。
3. 安装并打开应用，在“设置与模型 → 本地模型”中点击相应模型的“导入离线包”，选择 ZIP 文件。无需解压。
4. 等待文件校验和加载检查完成；问答模型可点击“准备问答模型”预热。

三个平台共用同一组离线模型 ZIP 包。平台运行库与语音分段模型已经随安装包附带。百度网盘可能要求登录或使用客户端，速度与账户及网络有关。离线包完整性清单随下载文件提供。

导入过程需要缓存及安装副本的空间；问答模型建议预留至少 6 GB 空闲空间，另计已下载 ZIP 本身。校验失败时请重新下载对应包，原有可用安装会保留。

## 下载报错

错误信息会显示失败文件、下载域名以及超时或 HTTP 状态。重试可以继续未完成下载；仍失败时切换到离线包导入。应用下载器不会自动读取浏览器代理设置，离线包提供了独立于该网络路径的安装方式。

使用国内源与离线包时仍会核对固定 SHA-256，再执行加载检查。模型来源与许可证可在设置卡片及离线包的 `NOTICE.txt`、`MODEL_LICENSE` 查看。
