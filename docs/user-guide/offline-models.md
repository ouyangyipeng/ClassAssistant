# 国内下载与离线模型

ClassFox 2.1.1 的语音识别与问答模型均优先使用魔搭 ModelScope 固定版本下载，直接在 App 中安装，不需要从网盘下载模型。网络中断会自动重试，已下载部分会保留；下载始终核对与原始源一致的大小和 SHA-256。

## 在 App 内安装（推荐）

1. 从[百度网盘可订阅目录](https://pan.baidu.com/s/5Wc6Xt2IZ9ehisotPnstGow)或[官网下载区](https://class.nexa-lang.com/#download)获取自己电脑对应的 2.1.1 安装包并安装。
2. 打开“设置与模型 → 本地模型”，分别点击语音和问答模型的“下载安装”。
3. 等待文件校验和加载检查完成，再点击“使用本地语音与问答”。

语音文件来自魔搭的 [gomodels/sherpa](https://modelscope.cn/models/gomodels/sherpa)，问答文件来自 [unsloth/Qwen3.5-4B-GGUF](https://modelscope.cn/models/unsloth/Qwen3.5-4B-GGUF)。两者都是上游模型的分发副本，应用只接受固定提交和匹配哈希的文件。原始源作为备用；VAD 与平台运行库已内置，无需额外下载。网盘仅用于分发安装包，可按百度网盘提供的方式订阅该目录。

## 已有离线包时导入

1. 安装 ClassFox 2.1 或更新版本。
2. 准备已有的 `ClassFox-sensevoice-small-offline.zip` 或 `ClassFox-qwen35-4b-offline.zip`。通常直接使用上面的 App 内下载即可。
3. 安装并打开应用，在“设置与模型 → 本地模型”中点击相应模型的“导入离线包”，选择 ZIP 文件。无需解压。
4. 等待文件校验和加载检查完成；问答模型可点击“准备问答模型”预热。

三个平台共用同一组离线模型 ZIP 包。平台运行库与语音分段模型已经随安装包附带。维护者可使用 `scripts/offline_models.py` 从固定来源生成离线包；获得包后按上述步骤导入。离线包完整性清单随下载文件提供。

导入过程需要缓存及安装副本的空间；问答模型建议预留至少 6 GB 空闲空间，另计已下载 ZIP 本身。校验失败时请重新下载对应包，原有可用安装会保留。

## 下载报错

错误信息会显示失败文件、下载域名以及超时或 HTTP 状态。重试可以继续未完成下载；仍失败时请记录文件名、域名及错误类别，连同应用版本反馈；已有离线包也可导入。应用下载器不会自动读取浏览器代理设置，离线包提供了独立于该网络路径的安装方式。

使用国内源与离线包时仍会核对固定 SHA-256，再执行加载检查。模型来源与许可证可在设置卡片及离线包的 `NOTICE.txt`、`MODEL_LICENSE` 查看。
