# 常见问题

## 没有 Key 能用吗？

可以启动、使用文本课堂和历史。下载安装本地语音与问答模型后可离线处理；BYOK 需要自己的账户和额度。2.0 不分发共享试用 Key。

## 首次救场为什么慢？

模型首次加载和文件校验需要时间。可在课前点击「准备问答模型」，等待实际就绪。实测冷/热样本见 [验证范围](../project/validation.md)，不要用单次数字推断所有电脑。

## 本地模式是不是原来的 local？

不是。1.x 的 `local` 调用了 Google 在线服务；2.0 将其明确标为兼容路径，真正离线使用 SenseVoice。WebSpeech 也依赖当前 WebView 与网络。

## macOS 提示无法验证开发者或文件损坏？

先确认下载来源、资产架构和 SHA-256，并阅读发布页的签名状态。临时签名包尚未经过 Developer ID 公证，不能保证 Gatekeeper 自动放行。不要关闭系统全局安全保护，也不要对未知来源文件批量移除隔离属性；需要正式签名包时等待该平台的公证资产。故障信息和验证范围见 [打包说明](../getting-started/packaging.md)。

## 为什么手机连接不到电脑？

确认两端处于同一可互通局域网，电脑已开启手机入口且地址仍有效。访客 Wi-Fi、AP 隔离、防火墙和 VPN 可能阻断连接。配对码过期、撤销或后台导致通道失效时重新配对，不把端口开放到公网。微信项目的域名和权限要求见 [微信指南](wechat.md)。

## 微信可以锁屏一直录音吗？

首版不承诺后台持续采集。进入后台或系统中断后暂停，单次达到 10 分钟也会停止，需要在前台手动继续。

## 总结失败会丢原文吗？

不会因生成失败删除原文。笔记只有完整成功后才保存，长课可以重试或先导出原文。磁盘满、设备丢失和人为删除仍需备份应对。
