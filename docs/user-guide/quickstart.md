# 首次使用

## 安装与启动

从 [GitHub Releases](https://github.com/ouyangyipeng/ClassAssistant/releases) 选择与系统和处理器一致的版本。macOS arm64 用于 Apple Silicon，x64 用于 Intel；Windows 首版目标为 x64。只下载发布页实际列出的资产，不把目标平台视为已经通过验证。

macOS 将应用拖入「应用程序」，Windows 运行安装程序。macOS 临时签名包未公证时仍可能被 Gatekeeper 拦截，先阅读该资产的签名说明，见 [常见问题](faq.md)。

## 选择本地或 BYOK

**本地模式：** 打开「设置 → 本地模型」，安装语音和问答模型。等待下载、摘要校验与加载检查完成后，再选择「使用本地语音与问答」。问答权重约 2.74 GB，语音模型约 240 MB，安装需要额外临时空间。首次下载需要互联网，之后处理课堂无需调用云端。

课前可点击「准备问答模型」。加载完成前，其他问答请求会等待同一次启动。模型运行会占用内存，退出应用后由课狐清理。

**BYOK：** 在「问答服务」选择预设或 OpenAI-compatible HTTPS 地址，分别保存 Key 和配置，再点击「保存配置并测试连接」。测试发送固定短文本，不含课堂内容，可能产生少量服务商费用。语音在「语音与麦克风」单独选择并填写对应凭据。

切换问答服务商时更新对应 Key。远程模型必须使用 HTTPS；电脑上自建的兼容服务可使用 loopback HTTP。本地模型未安装或 Key 未配置时，仍可创建文本课堂、保存原文和查看历史。

## 检查语音并开课

1. 在「语音与麦克风」检测输入设备，选择实际使用的麦克风。
2. 设置重点和危险关键词。提醒只根据新写入的条目触发。
3. 开始一堂课，填写名称，按需选择参考资料。
4. 选择记录方式，确认界面显示正在记录。权限拒绝或设备不可用时，界面会显示失败原因。
5. 不需要录音时选择文本输入。系统听写也可直接输入文本框，再保存为原文。

资料支持 PPTX、PDF、DOCX、TXT、Markdown；单份最多 25 MiB，超出时拆分上传。扫描 PDF 需要先做 OCR；课狐首版不含 OCR。

## 结束与回顾

结束课堂会停止录音。笔记生成是独立任务，失败后可重试；取消笔记不会删除原文。通过历史课堂查看记录，并导出原文或 Markdown 笔记。备份与旧版本导入见 [升级指南](migration.md)。

macOS 本地问答使用的 llama.cpp 官方运行时最低要求 **13.3**，安装前会检查；较旧系统仍可选择 BYOK 或已有兼容服务。
