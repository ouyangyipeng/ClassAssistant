# 微信小程序基础版

> 发布范围：微信小程序正式交付移至 v2.5。以下为开发预览说明；源码和本地验证已保留，不代表微信真机或上架验收通过。

微信版源码在 `mini-program/`。当前没有正式 AppID、服务端或域名，也未完成开发者工具和真机验收。首版提供可本地构建、可验证协议和行为的源码，不提供已上线的小程序码。

## 手机独立 BYOK

手机直接连接预设问答与语音服务商，不要求电脑持续在线。当前问答预设包括阿里云百炼北京/新加坡和 DeepSeek；语音使用 DashScope Fun-ASR 实时接口。Key 只在当前小程序内存中保存，切换服务商或地区时清除对应旧 Key，退出后重新填写。

课堂页提供录音、手动文字、关键词提醒、救场、进度、追问和总结；回顾页管理手机本机课堂。分享 Markdown 或复制全文由用户主动触发。单堂手机记录约束为 850,000 UTF-8 字节，超出或存储失败时停止继续保存并展示可保留内容。

录音使用微信原生权限和隐私同意界面。进入后台、来电/系统中断或单次 10 分钟结束后不会自动再次录音，需要回到前台手动继续。首版不承诺锁屏和后台持续听课。

## 连接电脑

1. 电脑安装并准备好本地语音和问答模型。
2. 电脑与手机加入同一可互通局域网。
3. 在桌面「设置 → 微信小程序」主动开启连接入口，生成一次性二维码。
4. 手机扫描后，两端核对 6 位数字，再在电脑上批准。
5. 手机创建自己的课堂。可以从电脑撤销连接，或关闭整个入口。

配对二维码有效期为 120 秒，批准连接最长 8 小时；重新连接需要重新配对。扫码秘密、方向和计数绑定 AES-GCM 加密，手机只获得自身课堂范围。手机不能读取桌面 Key、其他课堂、管理设置、资料路径或安装模型。不要转发配对二维码，也不要把局域网端口映射到公网。

手机每约 8 秒向电脑提交一段 PCM，识别延迟包含等待分段的时间；这与桌面持续录音的分句方式不同。电脑应持续运行，配对撤销后手机保留已保存的本机副本。重新配对不会开放旧电脑配对身份下的历史数据。

## 本地导入与正式配置

完整命令、项目目录、微信合法域名、SDK 要求、真机清单见 [源码说明](https://github.com/ouyangyipeng/ClassAssistant/blob/main/mini-program/README.md)。项目保留 URL 校验，不能通过关闭安全检查把开发环境成功当成正式可用。

正式发布需要可用 AppID、服务域名配置、隐私指引、真实录音和双端配对验收，以及微信审核。手机 BYOK 不需要项目方托管用户 Key；任意自定义服务地址不在首版范围。
