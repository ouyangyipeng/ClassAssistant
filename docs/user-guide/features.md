# 课堂工作流

## 记录与提醒

麦克风模式在独立语音进程中采集音频；浏览器模式依赖当前 WebView 的 Web Speech API，通常需要联网。文本模式无需麦克风，可粘贴文字或使用系统输入法听写。分段上传模式接受每段不超过 30 秒的 16 kHz、单声道、16 位 PCM WAV。

转录最终句追加保存，临时识别结果只用于界面展示。暂停与结束会处理已经收到的末句；错误、权限拒绝、服务断开和启动取消会改变课堂状态。后台意外退出后，重新打开会标记中断课堂，不会自动再次录音。

重点和危险关键词作用于新增原文。重复提交使用同一 `source_id` 时不会重复写入或再次提醒。识别错误可通过补充文字保留澄清，原始条目不由模型重写。

## 救场、进度与追问

救场使用最近课堂文字及相关资料；进度帮助回顾当前讲解；追问可加入具体问题。回答流式显示并记录首字、总耗时。网络、额度、Key、模型配置和不完整响应分别报错；应用不自动重试付费生成。

救场上下文有长度预算，不能代表整堂课的所有内容。长课笔记从发起时的原文快照分段整理，再合并；任务启动后的新条目留在原文中，不混入本次笔记。无法完整生成时不保存为成功笔记。

## 资料、历史与导出

上传的资料先独立解析为文本，开课时选择本堂引用资料。解析在受控子进程中运行，超过 30 秒会停止；损坏文件、压缩包异常和体积超限会显示可恢复错误。原始上传文件不作为长期附件保存。

历史按课堂组织，原文可以搜索、分页查看并导出。桌面使用系统保存对话框，写入完成后再原子替换目标。关闭前有未保存的浏览器识别文字时，会先提供保留入口。

## 窗口与外观

完整窗口适合看原文、资料和笔记；紧凑窗口保留课堂状态与主要操作并置顶。设置支持主题、强调色、字号、透明度和圆角；旧外观需显式导入，原始偏好保留。
