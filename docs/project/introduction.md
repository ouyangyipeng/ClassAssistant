课狐 ClassFox 是本地优先的课堂辅助工具，桌面使用 Tauri、React 和 Python，微信首版使用原生 TypeScript 页面。项目代码遵循 [MIT License](https://github.com/ouyangyipeng/ClassAssistant/blob/main/LICENSE)。

模型、运行时和第三方依赖有各自许可。SenseVoice 使用 FunASR Model License 1.1，不能将其笼统称为项目 MIT；Silero VAD 与 llama.cpp 使用 MIT，Qwen3.5 权重使用 Apache-2.0。固定下载版本、摘要和来源见 `api-service/classfox/model_catalog.py` 与仓库 [第三方说明](https://github.com/ouyangyipeng/ClassAssistant/blob/main/THIRD_PARTY_NOTICES.md)。

提交问题、测试和代码前阅读 [贡献指南](https://github.com/ouyangyipeng/ClassAssistant/blob/main/CONTRIBUTING.md)。macOS 与 WebSpeech 等既有贡献的处理记录见 [维护记录](maintenance.md)。
