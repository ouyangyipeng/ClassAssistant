## 本地延迟样本

设备为 M4 Pro / 48 GiB；受管 Qwen3.5 4B Q4_K_M、llama.cpp b10964、32,768 token context，固定合成二分查找问题。一次新进程请求首字 17.830 秒、总计 18.922 秒；记录到完整性检查 1.174 秒、模型启动到就绪 14.550 秒。紧接的第二次请求首字 57 毫秒、总计 1.111 秒。两次回答均包含有序前提，模型进程正常退出。

这是同机单次冷/热样本，不是速度 SLA 或准确率。操作系统缓存、内存压力、输入长度和设备会改变结果；应用提供课前显式预热入口。

公开中文音频样本通过源码离线 VAD/ASR 得到「开饭时间早上9点至下午5点。」，一次耗时 2.591 秒；4 秒合成静音得到空转录，耗时 2.241 秒。它们验证实际加载、解码、识别与退出，不等于真实课堂质量测试。
